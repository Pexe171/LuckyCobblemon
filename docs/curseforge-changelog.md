## Lucky Cobblemon: Fortune Blocks 0.6.1

- Added a dedicated playtest log for every game session.
- Logs include block variant, luck value, player, dimension, coordinates, selected category and detailed result.
- Added `/luckycobblemon logs` to display the current log file.
- Added configurable log retention with automatic cleanup of older files.
- Added a Brazilian Portuguese manual playtest checklist.

Logs are enabled by default and stored in `logs/luckycobblemon`. Cobblemon Raid Dens remains optional.
